Profiles


Audio response
System audio capture uses ScreenCaptureKit. macOS asks for Screen Recording permission. Microphone capture requires macOS 15 and microphone permission.
Media information
Choose a real metadata source. Music and Spotify require Automation permission and are read only while already running. There is no public universal Now Playing reader on macOS. Artwork is fetched only from Spotify artwork CDN hosts.


Playlists, profiles & application rules
Edit the saved configuration below. Playlists support timer, logon, daytime, dayofweek and never modes; rules run in array order. Preview validation occurs before saving.


Project editor
Open the selected scene in the document editor. Changes remain in the working document until saved; undo, redo and autosave use the editor service.
Scene objects
Edit text, font, transform, color, material and animation properties. Preview uses the current working resources; the source import is preserved.
Model and animation
The editable sidecar preserves the source model. FBX clips are matched by bone name and retargeted to the current skeleton; unsupported import data is reported.
Video / image sequence export
Exports a fixed-time scene through Metal, including time-indexed embedded video. The current profile writes opaque RGB without an audio track. Codec availability depends on this Mac or the configured encoder.


Steam Workshop
Public item details and Steam links work without an SDK. Subscription, download and publishing use your separately supplied official Steamworks library and an authenticated Steam client. The configured App ID must match the initialized application and have permission to use the target Workshop.
Steamworks connection
This build accepts the pinned SteamUGC v020 interface. Validate the SDK ABI on your Mac with the supplied header probe. SDK binaries and Steam credentials are not bundled.

External application runtimes
A Windows .exe requires a separately installed runtime such as Wine or CrossOver. This profile captures the resulting window through ScreenCaptureKit. Windows desktop IPC and input injection are not emulated. Mute or zero volume pauses the owned process group because a public process-volume API is unavailable. Intermediate app volume is controlled in the external application.
Arguments are passed directly without a shell. {entry} and {root} expand to the selected project paths. Native apps often need an empty argument array.
Without a title selector, capture chooses the largest window owned by the launched PID. Some Wine launchers hand off to another process and need an explicit title selector. Only the owned Unix process group is closed.
Compatibility & diagnostics
Runtime errors and unsupported content are reported here. Build-time checks do not validate Mac permissions, GPU rendering or Spaces behavior.
